## 🎯 Conceitos técnicos ensinados (reforçam teu estudo — já no Treinador)
- **Ransomware evoluiu**: simples → **dupla extorsão** (rouba dados antes de criptografar + ameaça vazar) → **tripla** (chantageia também os clientes/parceiros da vítima). [já é questão no app]
- Mentalidade **"assuma o hacker dentro da rede"**.
- Ataques reais são **BÁSICOS** (falta backup, falta controle de acesso), não sofisticados → o "arroz com feijão" (fundamentos: CIS/NIST/backup/acesso) evita a maioria.
- **Criptografia pós-quântica**: alerta G7 + CISA — criminosos roubam dado criptografado HOJE pra descriptografar no futuro com computação quântica ("harvest now, decrypt later").
- **Maturidade de segurança** é difícil de medir (sem metodologia universal); subir de maturidade 1→2 exige MUITO mais esforço (não é linear). É o que a ferramenta CIS mede.
